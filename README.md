A comprehensive collection of foundational machine learning algorithms, statistical methods, and deep learning architectures developed during the Methods of Knowledge Engineering (MIW) coursework at Polish-Japanese Academy of Information Technology.

\## Key Highlights

\* \*\*Mathematical Rigor:\*\* Implemented neural networks from scratch using pure NumPy to understand vectorization, cross-entropy loss, and gradient descent via backpropagation without abstract framework APIs.

\* \*\*Deep Architecture Coverage:\*\* Developed modern deep learning pipelines spanning Multi-Layer Perceptrons (MLP), Convolutional Neural Networks (CNN) for spatial data, and Recurrent Neural Networks (RNN) for sequence modeling.

\* \*\*Metric-Driven Evaluation:\*\* Validated all models with cross-validation, confusion matrices, and ROC-AUC curves.
